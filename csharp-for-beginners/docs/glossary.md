# Речник

Този речник събира основните термини на български и английски. Връщай се тук, когато срещнеш нова дума в урок.

| Български | English | Кратко обяснение |
|---|---|---|
| програма | program | Набор от инструкции, които компютърът изпълнява. |
| програмиране | programming | Писане на инструкции за компютър. |
| алгоритъм | algorithm | Последователност от стъпки за решаване на задача. |
| стъпка | step | Едно ясно действие от алгоритъм или програма. |
| код | code | Текстът на програмата, написан на програмен език. |
| синтаксис | syntax | Правилата за това как се пише кодът. |
| променлива | variable | Именувано място за пазене на стойност. |
| стойност | value | Данни, например `15` или `"Иван"`. |
| тип данни | data type | Вид стойност, например число, текст или истина/лъжа. |
| низ | string | Текстова стойност. |
| цяло число | integer | Число без дробна част. |
| условие | condition | Въпрос в кода с отговор `true` или `false`. |
| цикъл | loop | Код, който се повтаря. |
| метод | method | Именуван блок код, който изпълнява задача. |
| клас | class | Шаблон за създаване на обекти. |
| обект | object | Конкретно нещо, създадено по клас. |
| грешка | error | Проблем, който пречи на програмата да се компилира или изпълни правилно. |
| бъг | bug | Грешка в поведението или логиката на програмата. |
| дебъгване | debugging | Намиране и поправяне на грешки. |
| компилатор | compiler | Инструмент, който проверява и превежда кода. |
