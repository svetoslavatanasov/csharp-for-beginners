Урок 6

if, else и решения

Какво ще научиш

До края на този урок ще можеш да:

  • използваш типа bool и стойностите true и false;
  • сравняваш стойности с ==, !=, <, >, <= и >=;
  • караш програмата да избира с if и else;
  • подреждаш няколко възможности с else if;
  • свързваш условия с &&, || и !;
  • проверяваш дали въведено число е в разумни граници.

Защо това е важно

Досега всички редове в програмите ни се изпълняваха подред: първият, после вторият, после третият. Програмата не можеше да пропусне ред или да избере между два пътя. А истинските програми избират постоянно:

  • игра проверява дали имаш още живот;
  • сайт проверява дали паролата е вярна;
  • калкулаторът проверява дали не делиш на нула.

Всеки такъв избор започва с въпрос, на който отговорът е "да" или "не". В този урок ще научиш как да зададеш такъв въпрос на C# и как да кажеш на програмата какво да направи според отговора.

История с Byte

Днес Byte пази входа на влакчето в увеселителния парк. До входа има табела: "Ръст поне 140 см". Досега Byte работеше като нашите програми: изпълняваше стъпките една след друга и не пропускаше нищо. Затова в първия час пусна всички, дори едно момченце, високо едва 110 см. За щастие, шефът на парка го видя навреме и обясни: "Първо измерваш посетителя. Ако е висок поне 140 см, го пускаш. Ако не е, не го пускаш." Byte се замисля:

Byte: "Значи понякога трябва да пропусна стъпка?"

Да. Коя стъпка ще изпълни, зависи от отговора на един въпрос: "Ръстът поне 140 см ли е?" Отговорът е или "да", или "не". В програмирането такъв въпрос се нарича условие.

Byte: "Разбрах. Първо задавам въпроса. После според отговора избирам какво да направя."

Точно на това ще научим и програмите си: да избират кой код да изпълнят според условие.

Основно обяснение

Тип bool

В Урок 3 се запозна с типовете string, int и double. Сега идва още един: bool. Променлива от тип bool може да има само една от две стойности: true ("вярно", "да") или false ("невярно", "не"). Нищо друго. На български го наричаме булев тип, на името на английския математик Джордж Бул, който е изучавал такива стойности преди повече от 150 години.

bool isTall = true; създава променлива isTall със стойност true. Добре е името на bool променлива да звучи като въпрос: isTall значи "висок ли е?". true и false се пишат с малки букви и без кавички. "true" в кавички е текст, а не bool.

Оператори за сравнение

Рядко пишем true или false направо. По-често ги получаваме като отговор на въпрос: 5 по-голямо ли е от 3? В C# това се пише 5 > 3, а отговорът е true. Знакът > е оператор за сравнение. Операторът за сравнение сравнява две стойности и дава true или false. В C# има шест такива оператора:

ОператорВъпросПример
==равни ли са?5 == 3 е false
!=различни ли са?5 != 3 е true
<по-малко ли е?5 < 3 е false
>по-голямо ли е?5 > 3 е true
<=по-малко или равно ли е?4 <= 4 е true
>=по-голямо или равно ли е?3 >= 4 е false

Четири от тях се пишат с два знака, без интервал между тях: ==, !=, <= и >=. Внимавай с = и ==: = слага стойност в променлива, а == пита "равни ли са?". Въпрос с отговор true или false, като 5 > 3 или lives == 3, е условие. Нека пробваме:

bool isTall = true;
Console.WriteLine(isTall);
Console.WriteLine(5 > 3);
Console.WriteLine(5 == 3);
Console.WriteLine(5 != 3);
Console.WriteLine(4 <= 4);

Резултат:

True
True
False
True
True

Забележи, че C# показва True и False с главна буква, а в кода пишем true и false. Последният ред е True, защото <= пита "по-малко или равно ли е?". 4 не е по-малко от 4, но е равно на 4. Това стига.

if

Сега идва най-важното. В Урок 1 срещна стъпки като "Ако вратата се отвори, ...". if на английски значи "ако". С if казваме на програмата: "ако условието е вярно, изпълни тези редове". Ето пример с батерията на Byte:

int battery = 15;
if (battery < 20)
{
    Console.WriteLine("Батерията е слаба. Зареди ме!");
}
Console.WriteLine("Byte продължава работа.");

Резултат:

Батерията е слаба. Зареди ме!
Byte продължава работа.

След if в кръгли скоби стои условието battery < 20, а след него няма ;. Редовете между къдравите скоби { и } образуват блок. Блокът е група инструкции, които се изпълняват заедно. 15 < 20 е true, затова блокът се изпълнява и после програмата продължава с реда след }. Ако battery беше 80, условието щеше да е false. Тогава C# щеше да прескочи блока и щеше да покаже само Byte продължава работа.

Редът в блока е отместен навътре с 4 интервала. Това се нарича отстъп. На C# отстъпът не му трябва, но на хората помага да видят кои редове са в блока. Затова винаги го пишем.

if и else

Често искаме програмата да направи едно нещо, когато условието е вярно, и друго, когато не е. За това има else, което значи "иначе". Така можем да изпълним и обещанието от Урок 5. Там видя, че деление на 0 спира програмата, и обещахме да проверяваме делителя, преди да делим. Делителят е числото, на което делим. С if и else делим само когато той не е 0:

int cookies = 10;
int friends = 0;
if (friends != 0)
{
    Console.WriteLine("Всеки получава: " + (cookies / friends));
}
else
{
    Console.WriteLine("Няма приятели, няма деление.");
}

Резултат:

Няма приятели, няма деление.

friends != 0 пита "различно ли е от 0?". Тук friends е 0, затова отговорът е false. C# прескача първия блок и изпълнява блока на else. До делението изобщо не се стига и програмата не спира. Ако смениш friends на 2, ще видиш Всеки получава: 5. Блоковете на if и else са два възможни пътя. Всеки такъв път се нарича клон. Изпълнява се точно един от двата клона. else няма свое условие: той хваща всички случаи, в които условието на if е false.

else if

Понякога възможностите са повече от две. Тогава нареждаме else if, което значи "иначе, ако". Ето как Byte оценява резултат от игра:

int points = 75;
if (points >= 90)
{
    Console.WriteLine("Отлично!");
}
else if (points >= 50)
{
    Console.WriteLine("Добре.");
}
else
{
    Console.WriteLine("Опитай пак.");
}

Резултат:

Добре.

Проверява се отгоре надолу и се изпълнява само първият верен клон. 75 >= 90 е false, затова C# минава на следващата проверка. 75 >= 50 е true, затова C# показва Добре. и прескача всичко останало. Ако нито едно условие не е вярно, се изпълнява else накрая. Забележи, че всеки клон има свои { } и отстъп. C# позволява да пропуснеш къдравите скоби, когато в блока има само един ред, но тогава става трудно да се види кой ред към кой клон е. Затова винаги ги пишем.

Комбинирани условия

Понякога един въпрос не стига. Например на голямото влакче се качват само хора, които са високи поне 140 см и са навършили 10 години. Трябва и двете да са верни. За да свържем няколко условия в едно, използваме логически оператори. Логическият оператор свързва условия или обръща отговора им. Има три:

ОператорДава true, когатоПример
&& (и)и двете условия са верни5 > 3 && 2 > 1 е true
|| (или)поне едното условие е вярно5 > 3 || 2 > 10 е true
! (не)условието е невярно!(5 > 3) е false

&& е строг: ако дори едното условие е false, целият отговор е false. || е по-щедър: стига му едното условие да е true. А ! обръща отговора: true става false, а false става true. На английска клавиатурна подредба знакът | се пише с Shift и клавиша \.

Сравнение на текст

== и != работят и с текст. Два текста са равни само ако съвпадат буква по буква: "неделя" == "неделя" е true, а "Да" == "да" е false. В Урок 2 видя, че C# прави разлика между главни и малки букви. Същото важи и за текста в кавички. Дори един интервал в повече прави текстовете различни: "да " не е "да". Затова, ако програмата пита "да или не?", човекът трябва да напише отговора точно така, както го проверяваш в кода.

Четно или нечетно

Помниш ли % от Урок 5? Едно число е четно, когато се дели на 2 без остатък. Значи въпросът "четно ли е?" в C# е number % 2 == 0. За 8: 8 % 2 е 0, а 0 == 0 е true. За 7: 7 % 2 е 1, а 1 == 0 е false. C# първо изчислява % и чак после сравнява, затова не са нужни скоби. Нека съберем всичко от последните три части в една програма:

int age = 15;
Console.WriteLine(age >= 13 && age <= 19);
string day = "неделя";
Console.WriteLine(day == "събота" || day == "неделя");
bool isRaining = false;
Console.WriteLine(!isRaining);
Console.WriteLine("Да" == "да");
int number = 8;
Console.WriteLine(number % 2 == 0);

Резултат:

True
True
True
False
True

Първият ред е True, защото 15 е поне 13 и най-много 19. Така се проверява дали число е между две граници. Вторият е True, защото денят е неделя, а на || му стига едното сравнение. Третият е True, защото ! обръща false в true: "не вали". Четвъртият е False заради главното Д. Последният показва, че 8 е четно.

Проверка на входа

В Урок 4 приехме, че човекът винаги въвежда правилни стойности, и обещахме: "По-късно, когато учим условия, ще проверяваме входа по-внимателно." Сега е моментът. Ако програмата пита за оценка от 2 до 6, човекът може да напише 7. int.Parse ще превърне текста в число без проблем, но 7 няма смисъл като оценка. Такава стойност е невалидна, тоест не може да бъде приета. С if проверяваме дали числото е в разумни граници, преди да го използваме:

Console.WriteLine("Въведи оценка от 2 до 6:");
string gradeText = Console.ReadLine();
int grade = int.Parse(gradeText);
if (grade < 2 || grade > 6)
{
    Console.WriteLine("Невалидна оценка.");
}
else
{
    Console.WriteLine("Записах оценка " + grade + ".");
}

Ако човекът въведе:

7

резултатът ще бъде:

Въведи оценка от 2 до 6:
Невалидна оценка.

Ако човекът въведе:

5

резултатът ще бъде:

Въведи оценка от 2 до 6:
Записах оценка 5.

Условието grade < 2 || grade > 6 пита "извън границите ли е оценката?". Стига едното сравнение да е вярно: оценката е или твърде малка, или твърде голяма. Ако човекът напише дума, например много, int.Parse пак ще спре програмата, както в Урок 4. Засега продължаваме да приемаме, че се въвежда число. Но вече можем да проверим дали числото има смисъл.

Визуално обяснение

Ето как if и else разделят програмата на два пътя при табелата на Byte:

          +-----------------+
          | height >= 140 ? |
          +-----------------+
           | да          | не
           v             v
  [ "Заповядай!" ]  [ "Съжалявам..." ]
           |             |
           +------+------+
                  v
       [ програмата продължава ]

Програмата минава само по единия път. После двата пътя се събират и програмата продължава надолу. Веригата с else if пък прилича на стълба. C# слиза стъпало по стъпало и спира на първото вярно условие:

points >= 90 ?  --да-->  "Отлично!"
   | не
   v
points >= 50 ?  --да-->  "Добре."
   | не
   v
"Опитай пак."

При 75 точки първото стъпало казва "не", а второто казва "да". C# показва Добре. и не гледа по-надолу.

Първи пример

Сега да напишем програмата на Byte за влакчето. Тя пита за ръста и решава кое съобщение да покаже:

Console.WriteLine("Колко сантиметра си?");
string heightText = Console.ReadLine();
int height = int.Parse(heightText);

if (height >= 140)
{
    Console.WriteLine("Заповядай на влакчето!");
}
else
{
    Console.WriteLine("Съжалявам, още не можеш да се качиш.");
}

Ако човекът въведе:

150

резултатът ще бъде:

Колко сантиметра си?
Заповядай на влакчето!

Ако човекът въведе:

120

резултатът ще бъде:

Колко сантиметра си?
Съжалявам, още не можеш да се качиш.

Разбивка на кода

Първите три реда са познати от Урок 4: програмата показва въпрос, чете отговора и го превръща в цялото число height. После if (height >= 140) започва решението. В кръглите скоби е условието. C# го изчислява: при 150 то е true, а при 120 е false. След ) няма ;, защото условието не е отделна инструкция, а началото на if.

Блокът между { и } веднага след условието е блокът на if. Той показва Заповядай на влакчето! и се изпълнява само когато условието е true. Редът в него е с отстъп, за да се вижда, че принадлежи на блока. else няма свое условие. Неговият блок показва Съжалявам, още не можеш да се качиш. и се изпълнява само когато условието е false. След последната } програмата продължава надолу. В тази програма след нея няма други редове, затова програмата свършва.

Чести грешки

Грешка 1: = вместо ==

int lives = 3;
if (lives = 0)
{
    Console.WriteLine("Край на играта.");
}

Защо е проблем:

Едно = не пита, а слага стойност. lives = 0 записва 0 в lives и дава число. if обаче иска отговор true или false. C# дава грешка: не може int да стане bool. Програмата няма да се стартира.

Поправка:

int lives = 0;
if (lives == 0)
{
    Console.WriteLine("Край на играта.");
}

Резултат:

Край на играта.

Грешка 2: Точка и запетая след условието

int age = 10;
if (age >= 18);
{
    Console.WriteLine("Можеш да караш кола.");
}

Резултатът ще бъде:

Можеш да караш кола.

Защо е проблем:

Човекът е на 10 години, а програмата му разрешава да кара кола. ; завършва инструкцията, затова C# чете if (age >= 18); като "ако условието е вярно, не прави нищо". Блокът отдолу вече не е свързан с if и се изпълнява винаги. C# не дава грешка, а само предупреждение. Предупреждението е бележка от C#, че нещо изглежда подозрително, но програмата пак се стартира. Затова тази грешка е коварна: програмата работи, но не прави това, което искаме.

Поправка:

int age = 10;
if (age >= 18)
{
    Console.WriteLine("Можеш да караш кола.");
}
Console.WriteLine("Край.");

Резултат:

Край.

Грешка 3: Общото условие е първо

int points = 95;
if (points >= 50)
{
    Console.WriteLine("Добре.");
}
else if (points >= 90)
{
    Console.WriteLine("Отлично!");
}

Резултатът ще бъде:

Добре.

Защо е проблем:

Искахме 95 точки да дадат Отлично!. Но C# спира на първото вярно условие. 95 е поне 50, затова още първото условие е true. До проверката за 90 C# изобщо не стига. Всяко число, което е поне 90, е и поне 50, така че Отлично! никога няма да се покаже. Във веригата с else if подреждай от най-конкретното към най-общото условие.

Поправка:

int points = 95;
if (points >= 90)
{
    Console.WriteLine("Отлично!");
}
else if (points >= 50)
{
    Console.WriteLine("Добре.");
}

Резултат:

Отлично!

Грешка 4: Двойно сравнение като в математиката

int age = 15;
if (13 <= age <= 19)
{
    Console.WriteLine("Тийнейджър си.");
}

Защо е проблем:

В математиката такъв двоен запис е нормален, но C# сравнява по две стойности. Първо изчислява 13 <= age и получава true. После трябва да сравни true <= 19, а това няма смисъл: "вярно" не може да е по-малко от число. C# дава грешка и програмата няма да се стартира. Двете сравнения се пишат отделно и се свързват с &&.

Поправка:

int age = 15;
if (age >= 13 && age <= 19)
{
    Console.WriteLine("Тийнейджър си.");
}

Резултат:

Тийнейджър си.

Грешка 5: Променливата е създадена вътре в блока

int points = 120;
if (points >= 100)
{
    string medal = "злато";
}
Console.WriteLine(medal);

Защо е проблем:

Променлива, създадена вътре в { }, съществува само до затварящата }. Затова на последния ред C# казва, че medal не съществува, и програмата няма да се стартира. Създай променливата преди блока, а в блока само смени стойността й.

Поправка:

int points = 120;
string medal = "няма";
if (points >= 100)
{
    medal = "злато";
}
Console.WriteLine(medal);

Резултат:

злато

Как мисли програмистът

Преди да напишеш if, спри за момент и си задай няколко въпроса. Нека ги пробваме с табелата на Byte "Ръст поне 140 см":

  1. Какъв е въпросът с отговор да или не? Ръстът поне 140 см ли е?
  2. Как се пише като сравнение? "Поне 140" значи 140 или повече: height >= 140.
  3. Какви са всички възможни случаи? Два: поне 140 (качва се) и под 140 (не се качва).
  4. Ако случаите са повече, в какъв ред ще ги проверя? От най-конкретния към най-общия.
  5. С кои стойности ще пробвам програмата? С граничните: 139, 140 и 141.

Гранична стойност е число точно на границата, където отговорът се сменя, или съвсем до нея. Тук границата е 140. При 139 програмата трябва да откаже, а при 140 и 141 да пусне. Защо точно тези числа? Ако по невнимание напишеш height > 140 вместо height >= 140, програмата ще работи правилно при 150 и при 120. Само при 140 ще откаже на човек, който има право да се качи.

Byte: "Не пробвам с кое да е число. Пробвам границата и съседите й."

bool result3 = a > 100 || b == 10;

  2. Каква е разликата между = и ==?
  3. Кога се изпълнява кодът в else?
  4. Ако няколко условия в else if са верни, кой блок се изпълнява?
  5. Каква е разликата между && и ||?
  6. Какво прави !?
  7. Как да провериш дали едно число е четно?
  8. Защо "Да" == "да" дава false?

Обобщение

В този урок научи:

  • bool има само две стойности, true и false, и точно такъв отговор дават операторите за сравнение ==, !=, <, >, <= и >=;
  • = слага стойност, а == пита "равни ли са?";
  • if изпълнява блока си само когато условието е true, а блокът на else се изпълнява, когато е false;
  • при else if C# проверява отгоре надолу и изпълнява само първия верен клон;
  • && иска и двете условия да са верни, || иска поне едното, а ! обръща отговора;
  • текстът се сравнява буква по буква и главните букви имат значение;
  • number % 2 == 0 проверява дали числото е четно;
  • с if можеш да провериш дали въведено число е в разумни граници и дали делителят не е 0;
  • променлива, създадена в блок, не съществува след него.

Най-важната идея:

Условието е въпрос с отговор true или false.
if изпълнява блока си само когато отговорът е true.
